# Chem-eng-Calculators
# Chemical Engineering & Math Calculators

مجموعة أدوات وبرمجيات مفتوحة المصدر بلغة Python لحل المعادلات الرياضية وحسابات الهندسة الكيميائية.

## المميزات الحالية:
- حساب معادلات الغازات المثالية والحقيقية.
- حل المعادلات التفاضلية والتكامل العددي للطلاب.

## كيفية الاستخدام:
سيتم إضافة الأكواد البرمجية قريباً.
